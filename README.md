# Parallex Bank Prototype

Enterprise onboarding recovery and customer lifecycle intelligence platform.

Built with:
- Next.js 15
- TypeScript
- TailwindCSS
- Framer Motion
- Mock APIs
- Enterprise CRM simulation

---

# Installation

```bash
npm install
````

Run development:

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```
